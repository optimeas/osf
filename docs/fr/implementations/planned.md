# Autres langages (prévus)

Outre les implémentations disponibles (Delphi, Rust, Python, C++ et
[Java](java.md)), d'autres langages sont envisagés.
Pour eux, il n'existe pour l'instant que des espaces réservés dans le dépôt,
mais pas encore de code. Comme OSF est un format documenté ouvertement et
volontairement simple, chacun de ces raccordements peut être réalisé de
manière autonome.

| Langage | Priorité prévue |
|---|---|
| **C** | Raccordement léger et portable pour un usage embarqué et système. À court terme, l'ABI C [`osf-c`](cpp.md) est déjà disponible via l'implémentation C++. |

L'état actuel — et la question de savoir si des travaux ont déjà commencé —
est tenu à jour par le dépôt sur [GitHub](https://github.com/optimeas/osf). Si
un langage particulier vous intéresse, il vaut la peine de consulter la
[spécification](../osf_general.md) et les implémentations existantes comme
modèle.

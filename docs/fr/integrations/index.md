## Intégrations

Ce chapitre décrit le raccordement d'OSF à des **écosystèmes** et chaînes
d'outils existants — par exemple l'écosystème scientifique Python ou les
frameworks de données et d'IA. Chaque intégration est documentée de manière
autonome et contient un aperçu de l'API, un guide d'installation et des
renvois vers le code source.

Les **implémentations** du format lui-même par langage (Delphi, Rust, Python,
C++, Java …) sont décrites dans le chapitre dédié
[Implémentations](../implementations/index.md).

Actuellement disponible :

- **[Python](python.md)** — Le paquet `osfdata` avec prise en charge complète
  d'OSF4/OSF5, intégration NumPy et fondation Rust.

Des raccordements à Apache Arrow, PyTorch, TensorFlow, MCP et
LangChain sont prévus — voir [Intégrations prévues](planned.md). L'état actuel
est tenu à jour par le dépôt sur [GitHub](https://github.com/optimeas/osf).

# Otros lenguajes (planificados)

Además de las implementaciones disponibles (Delphi, Rust, Python, C++ y
[Java](java.md)), están previstos otros lenguajes.
Hasta ahora existen marcadores de posición en el repositorio para ellos,
pero todavía no hay código. Dado que OSF es un formato documentado
abiertamente y deliberadamente sencillo, cada una de estas integraciones
puede realizarse de forma independiente.

| Lenguaje | Enfoque planificado |
|---|---|
| **C** | Integración ligera y portable para uso embebido y de sistema. A corto plazo, la C-ABI [`osf-c`](cpp.md) ya está disponible a través de la implementación en C++. |

El estado actual —y si ya se ha comenzado a trabajar— se mantiene en el
repositorio de [GitHub](https://github.com/optimeas/osf). Si le interesa un
lenguaje concreto, merece la pena consultar la
[especificación](../osf_general.md) y las implementaciones existentes como
modelo.

## Integraciones

Este capítulo describe la integración de OSF en **ecosistemas** y cadenas de
herramientas existentes, por ejemplo el ecosistema científico de Python o los
frameworks de datos e IA. Cada integración está documentada de forma
independiente e incluye un resumen de la API, instrucciones de instalación y
enlaces al código fuente.

Las **implementaciones** del propio formato en distintos lenguajes (Delphi,
Rust, Python, C++, Java …) se describen en su propio capítulo,
[Implementaciones](../implementations/index.md).

Actualmente disponible:

- **[Python](python.md)** — El paquete `osfdata` con compatibilidad completa
  con OSF4/OSF5, integración con NumPy y base en Rust.

Están planificadas integraciones con Apache Arrow, PyTorch, TensorFlow, MCP y
LangChain — véase [Integraciones planificadas](planned.md). El estado actual
se mantiene en el repositorio de [GitHub](https://github.com/optimeas/osf).

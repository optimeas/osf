## Herramientas

Este capítulo reúne las herramientas de línea de comandos y los programas auxiliares relacionados con el formato OSF. Cada herramienta está documentada de forma independiente e incluye una descripción general del manejo, una referencia de comandos y ejemplos.

Disponible actualmente:

- **[osftool](osftool.md)** — Herramienta de línea de comandos basada en verbos para combinar, exportar, inspeccionar, convertir y verificar archivos OSF y OSFZ.

Encontrará el estado actual en [GitHub](https://github.com/optimeas/osf).

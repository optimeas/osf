## Integrationen

Dieses Kapitel beschreibt die Anbindung von OSF an bestehende **Ökosysteme**
und Werkzeugketten — etwa das wissenschaftliche Python-Ökosystem oder
Daten-/KI-Frameworks. Jede Integration ist eigenständig dokumentiert und
enthält eine API-Übersicht, Installationsanleitung und Verweise auf den
Quellcode.

Die Sprach-**Implementierungen** des Formats selbst (Delphi, Rust, Python,
C++, Java …) sind im eigenen Kapitel
[Implementierungen](../implementations/index.md) beschrieben.

Aktuell verfügbar:

- **[Python](python.md)** — Das `osfdata`-Paket mit vollständiger
  OSF4/OSF5-Unterstützung, NumPy-Integration und Rust-Foundation.

Geplant sind Anbindungen an Apache Arrow, PyTorch, TensorFlow, MCP und
LangChain — siehe [Geplante Integrationen](planned.md). Den aktuellen Status
führt das Repository auf [GitHub](https://github.com/optimeas/osf).

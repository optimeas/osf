# OSF — General Concepts

> **Note:** This document is a placeholder. The full specification will be added here.

This document will cover the concepts that are common to all versions of the Open Streaming Format:

- Design goals: streaming-first, robustness, compactness
- Channel model: equidistant vs. time-stamped channels
- Data types: scalar, vector, matrix, binary blob
- Time representation
- Data block structure
- Metadata and header conventions
- Relationship between OSF4 and OSF5

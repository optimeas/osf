## Integrazioni

Questo capitolo descrive il collegamento di OSF a **ecosistemi** e
catene di strumenti esistenti — ad esempio l'ecosistema scientifico
Python o i framework per dati/IA. Ogni integrazione è documentata in
modo autonomo e contiene una panoramica dell'API, le istruzioni di
installazione e i riferimenti al codice sorgente.

Le **implementazioni** del formato nei vari linguaggi (Delphi, Rust,
Python, C++, Java …) sono descritte nel capitolo dedicato
[Implementazioni](../implementations/index.md).

Attualmente disponibile:

- **[Python](python.md)** — Il pacchetto `osfdata` con supporto completo
  di OSF4/OSF5, integrazione NumPy e foundation Rust.

Sono pianificati collegamenti con Apache Arrow, PyTorch, TensorFlow, MCP
e LangChain — vedere [Integrazioni pianificate](planned.md). Lo stato
attuale è mantenuto dal repository su
[GitHub](https://github.com/optimeas/osf).

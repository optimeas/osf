## Tools

This chapter collects the command-line tools and utilities around the OSF format. Each tool is documented independently and contains a usage overview, a command reference, and examples.

Currently available:

- **[osftool](osftool.md)** — A verb-based command-line tool for merging, exporting, inspecting, converting, and verifying OSF and OSFZ files.

For the current status, see [GitHub](https://github.com/optimeas/osf).

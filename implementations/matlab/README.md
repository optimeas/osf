# OSF — MATLAB Implementation

![Status](https://img.shields.io/badge/status-planned-lightgrey.svg)

## Target Platform

Engineering analysis workflows in MATLAB and Simulink. Intended for researchers and engineers who receive OSF files from measurement systems and need to load them into MATLAB for analysis.

## What This Implementation Will Provide

- **Reader only**: load OSF4 and OSF5 files into MATLAB as structured data
- Returns channel data as MATLAB arrays and metadata as structs
- Distributed as a MATLAB toolbox or a set of `.m` files

## Status

**Planned.** Implementation has not started.

## Dependencies

- MATLAB R2021a or later

## Notes

This is a **reader-only** implementation. Writing OSF files from MATLAB is out of scope. The goal is to enable engineers to work with OSF data without leaving their existing MATLAB workflows.

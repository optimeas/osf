# OSF — Java Implementation

![Status](https://img.shields.io/badge/status-planned-lightgrey.svg)

## Target Platform

Enterprise applications, server-side data pipelines, and Android mobile data logging. Targets Java 11 and later.

## What This Implementation Will Provide

- **Reader**: full OSF4 and OSF5 reader
- **Writer**: OSF5 writer
- `java.io.InputStream` / `OutputStream`-compatible API
- Maven and Gradle artifacts
- Android compatibility (API level 26+)

## Status

**Planned.** Implementation has not started.

## Dependencies

- Java 11+
- No mandatory third-party dependencies for the core library

## Notes

The Java implementation covers both JVM server deployments and Android mobile devices used for field data logging.

# OSF — C# Implementation

![Status](https://img.shields.io/badge/status-planned-lightgrey.svg)

## Target Platform

Windows desktop applications, industrial automation software, and HMI tools built on the .NET ecosystem. Targets .NET 6 and later.

## What This Implementation Will Provide

- **Writer**: streaming writer for OSF4 and OSF5
- **Reader**: full OSF4 and OSF5 reader with LINQ-friendly channel enumeration
- NuGet package for easy integration
- `System.IO.Stream`-compatible API

## Status

**Planned.** Implementation has not started.

## Dependencies

- .NET 6 or later
- `System.Text.Json` (built-in) for OSF5 header parsing

## Notes

Targets the Windows industrial tooling and automation space where .NET is the dominant platform.
